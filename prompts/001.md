Goal:
Add a new PostgreSQL database helper module to the existing Go SDK. The module must support:

1. Auto create database if it does not exist.
2. Auto create and maintain a migration table.
3. Auto run SQL migrations in order.
4. Use embedded migrations via Go `embed.FS`.
5. Use `pgx/v5` and `pgxpool`.
6. Must not break or rewrite existing SDK network/proxy/websocket code.
7. Must be usable by other projects as a reusable SDK package.

Important constraints:

* Do not remove existing packages, APIs, examples, tests, or module structure.
* Do not rename existing public APIs unless absolutely necessary.
* Do not introduce global side effects.
* PostgreSQL `CREATE DATABASE` must not be executed inside a transaction.
* Table migrations should be executed transactionally.
* Migration execution must be concurrency-safe using PostgreSQL advisory lock.
* Migration files must be sorted by numeric prefix, for example:

  * `001_init.sql`
  * `002_add_indexes.sql`
  * `003_add_scan_progress.sql`
* Already-applied migrations must not run again.
* If a migration version already exists, skip it.
* Add checksum storage for migrations.
* If possible, detect checksum mismatch for already-applied migrations and return a clear error.
* Use safe identifier quoting for database name.
* Support LAN PostgreSQL usage such as host `192.168.1.5`.
* Support `sslmode=disable`.

Behavior:

`Open`:

* Normalize config defaults:

  * Host default: `127.0.0.1`
  * Port default: `5432`
  * AdminDatabase default: `postgres`
  * SSLMode default: `disable`
  * migrationsDir default: `migrations`
* If `AutoCreateDatabase == true`, call `EnsureDatabase`.
* Connect to target database using `pgxpool`.
* Ping database.
* If `AutoMigrate == true`, call `Migrate`.
* Return ready-to-use `*pgxpool.Pool`.

`EnsureDatabase`:

* Connect to admin database.
* Check `pg_database` for target database.
* If missing, run `CREATE DATABASE "<db_name>"`.
* Use safe identifier quoting.
* Return useful wrapped errors.

`Migrate`:

* Create table if not exists:

```sql
CREATE TABLE IF NOT EXISTS schema_migrations (
    version BIGINT PRIMARY KEY,
    name TEXT NOT NULL,
    checksum TEXT NOT NULL,
    applied_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

* Acquire advisory lock before migration:

```sql
SELECT pg_advisory_lock($1);
```

* Release lock after migration:

```sql
SELECT pg_advisory_unlock($1);
```

* Read `.sql` files from embedded filesystem.
* Parse numeric migration version from filename prefix.
* Reject duplicate versions.
* Sort ascending by version.
* For each migration:

  * If version does not exist, run SQL inside transaction.
  * Insert into `schema_migrations`.
  * Commit.
  * Rollback on error.
  * If version exists and checksum differs, return clear checksum mismatch error.
  * If version exists and checksum matches, skip.

```go
    "context"
    "embed"
    "log"

func main() {
    ctx := context.Background()

    pool, err := dbpostgres.Open(ctx, dbpostgres.Config{
        Host: "192.168.1.5",
        Port: 5432,
        User: "deskaone",
        Password: "change_me",
        Database: "wolf",
        SSLMode: "disable",
        AutoCreateDatabase: true,
        AutoMigrate: true,
    }, migrations, "migrations")
    if err != nil {
        log.Fatal(err)
    }
    defer pool.Close()

    log.Println("database ready")
}
```
